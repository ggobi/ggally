# [GGally](http://ggobi.github.io/ggally/): Extension to [ggplot2](https://ggplot2.tidyverse.org/)

[`ggplot2`](https://ggplot2.tidyverse.org/) is a plotting system for R
based on the grammar of graphics.
[`GGally`](https://ggobi.github.io/ggally/) extends ggplot2 by adding
several functions to reduce the complexity of combining geoms with
transformed data. Some of these functions include a pairwise plot
matrix, a scatterplot plot matrix, a parallel coordinates plot, a
survival plot, and several functions to plot networks.

## Installation

To install this package from GitHub or
[CRAN](https://cran.r-project.org/package=GGally), do the following from
the R console:

``` r

# Github
pak::pak("ggobi/ggally")
```

``` r

# CRAN
install.packages("GGally")
```
