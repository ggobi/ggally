# NA plot

Draws a large `NA` in the middle of the plotting area. This plot is
useful when all X or Y data is `NA`

## Usage

``` r
ggally_na(data = NULL, mapping = NULL, size = 10, color = "grey20", ...)

ggally_naDiag(...)
```

## Arguments

- data:

  ignored

- mapping:

  ignored

- size:

  size of the geom_text 'NA'

- color:

  color of the geom_text 'NA'

- ...:

  other arguments sent to geom_text
