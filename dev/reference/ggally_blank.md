# Blank plot

Draws nothing.

## Usage

``` r
ggally_blank(...)

ggally_blankDiag(...)
```

## Arguments

- ...:

  other arguments ignored

## Details

Makes a "blank" ggplot object that will only draw white space

## See also

[`ggplot2::element_blank()`](https://ggplot2.tidyverse.org/reference/element.html)
