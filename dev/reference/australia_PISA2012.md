
## Details

The Programme for International Student Assessment (PISA) is a triennial
international survey which aims to evaluate education systems worldwide
by testing the skills and knowledge of 15-year-old students. To date,
students representing more than 70 economies have participated in the
assessment.

While 65 economies took part in the 2012 study, this data set only
contains information from the country of Australia.
